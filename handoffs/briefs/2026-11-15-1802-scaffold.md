test && pnpm build` all pass, Postgres runs via `docker compose up -d db`, and
the folder layout enforces the PRD's separation (Meta integration / domain /
persistence / worker / UI). No product features yet.

## Phase
Set up, at the repo root:
1. Next.js (latest stable, App Router, `src/` dir, TypeScript `strict: true`
   plus `noUncheckedIndexedAccess`), Tailwind CSS, shadcn/ui initialised
   (`components.json`, `src/components/ui/` with just `button` to prove it).
   Default Node runtime; no `runtime = 'edge'`.
2. `package.json`: `"name": "fewchat"`, `"license": "MIT"`, `packageManager`
   pinned to pnpm 12, `engines.node >=22`. Scripts: `dev`, `build`, `start`,
   `lint`, `typecheck` (`tsc --noEmit`), `test` (vitest run, unit only),
   `test:db` (vitest project needing Postgres — may be empty for now),
   `test:e2e` (playwright), `db:generate`, `db:migrate` (drizzle-kit),
   `worker` (runs `src/worker/main.ts` via `tsx`).
3. Drizzle + `postgres` (postgres.js) driver: `drizzle.config.ts`,
   `src/db/client.ts`, `src/db/schema.ts` with **only** a comment saying the
   schema lands in the next phase. Env read through `src/config/env.ts`
   validated with zod (DATABASE_URL, APP_URL, META_APP_ID, META_APP_SECRET,
   META_WEBHOOK_VERIFY_TOKEN, META_GRAPH_API_VERSION, TOKEN_ENCRYPTION_KEY,
   ADMIN_PASSWORD_HASH, SESSION_SECRET) — lazily, so `pnpm build` passes
   without a `.env`.
4. Folders with an `index.ts` or README line each stating their role:
   `src/meta/` (Graph API client only), `src/domain/` (pure logic, no I/O),
   `src/db/`, `src/worker/` (`main.ts` that logs "worker started" and exits
   cleanly on SIGTERM), `src/app/` (routes/UI only).
5. Vitest config with two projects: `unit` (`src/**/*.test.ts`, default) and
   `db` (`src/**/*.db.test.ts`). One trivial unit test so `pnpm test` runs.
6. Playwright config (`e2e/`, one smoke test that the home page renders);
   don't run e2e as part of `pnpm test`. Don't download browsers in checks.
7. `docker-compose.yml`: `db` (postgres:17, healthcheck, named volume, port
   5432) and a commented-out `app`/`worker` stub. A `Dockerfile` for the app
   (multi-stage, Next standalone output).
8. `.env.example` with every var above, placeholder values and a one-line
   comment each. ESLint (Next's flat config) + Prettier. `.gitignore` already
   exists — append only what's missing.
9. Home page: a plain placeholder "FewChat — Less automation. Just what you
   need." No dashboard work.

Lockfile: you may create `pnpm-lock.yaml` with `pnpm install` this one time
(Jarvis normally owns it) — name it in the handoff.
