## Phase
1. `src/domain/matching.ts` — `matchComment(text, rule)` where rule is
   `{ triggerType: "keyword" | "any", keyword?, matchMode?: "exact" | "whole_word" | "contains" }`,
   returns `{ matched: boolean, reason }`. Normalise both sides with NFKC +
   `toLocaleLowerCase("und")` (case-insensitive, Unicode-aware).
   - exact: comment with surrounding whitespace, punctuation (`\p{P}`) and
     emoji/symbols (`\p{S}`, `\p{Extended_Pictographic}`) stripped equals the
     keyword; inner whitespace collapsed. So `"JARVIS!"`, `"  jarvis 🔥"` match.
   - whole_word: keyword (may be a multi-word phrase; collapse its whitespace)
     appears bounded by start/end or a non-letter/non-number/non-mark char
     (`[^\p{L}\p{N}\p{M}]`), using the `u` flag and escaping regex chars in
     the keyword. PRD table must pass: GUIDE ✓, guide please ✓, Can I have
     the GUIDE? ✓, GUIDELINES ✗. Also: `#guide` ✓, `guide's` ✓, non-Latin
     (`"Отправь ГАЙД"` with keyword `гайд`) ✓, CJK keyword inside CJK text
     falls back to contains (no word boundaries in CJK — document it).
   - contains: substring after normalisation.
   - any: matched for any non-empty (after trim) text; empty/whitespace-only/
     undefined → not matched with reason `empty`.
   - keyword trigger with empty keyword → not matched, reason `invalid_rule`.
2. `src/domain/template.ts` — `renderTemplate(template, { username?, keyword?, resourceUrl })`
   and `validateTemplate(template)`. Placeholders: `{username}`,
   `{keyword}`, `{resource_url}` only; plain string replacement, never eval.
   Missing `username`/`keyword` renders as empty and tidies the result
   (`"Hey {username}! "` → `"Hey! "`: drop one adjacent space; collapse double
   spaces; trim). `validateTemplate` reports unknown placeholders
   (`{foo}`), a template without `{resource_url}` (error — PRD: resource must
   be in the first reply), and rendered length over `MAX_DM_TEXT_LENGTH`
   (export as 1000, with a `// TODO verify against docs/research/meta-api.md`).
   Export `DEFAULT_DM_TEMPLATE = "Hey! Here's the resource you asked for: {resource_url}"`.
3. `src/domain/resource-url.ts` — `validateResourceUrl(input)` →
   `{ ok: true, url, warnings: ("not_https")[] } | { ok: false, error }`.
   Only `http:`/`https:`; reject credentials in URL, whitespace/control chars,
   length > 2048, missing host. No network calls.
4. `src/domain/eligibility.ts` — `PRIVATE_REPLY_WINDOW_MS` (7 days) and
   `checkEligibility(commentCreatedAt, now, { safetyMarginMs = 1h })` →
   `{ eligible, expiresAt }`. Comment in the future (clock skew) is eligible.
5. `src/domain/rate-limit.ts` — pure decision over recent send timestamps:
   `decideSend(sentAtMs[], now, { perHour = 600, burstPerMinute = 30 })` →
   `{ allowed: true } | { allowed: false, retryAt }` (rolling windows). And
   `computeBackoff(attempt, { baseMs = 30s, maxMs = 30min, random, retryAfterMs?, expiresAt?, now })`
   → next run time or `null` when it would pass `expiresAt` (caller then
   marks EXPIRED). Retry-After wins over exponential when larger; full jitter.
6. One test file per module, covering the cases above plus emoji-only,
   punctuation-heavy, mixed-script and very long inputs.
