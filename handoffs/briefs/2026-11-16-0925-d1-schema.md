Postgres design translated to Drizzle's SQLite dialect, `migrations/0000_*.sql`

## Phase
1. `src/db/schema.ts`: the six tables above in `drizzle-orm/sqlite-core`, with
   status `CHECK`s, FKs, and the indexes. Export inferred row/insert types.
2. `pnpm db:generate` → `migrations/0000_<name>.sql` (commit it as generated;
   don't hand-edit unless drizzle-kit can't express a `CHECK` or partial
   index, and then say so). It must apply cleanly with
   `pnpm db:migrate:local` (point `--persist-to` at your scratchpad).
3. `src/db/deliveries.ts`: `recordEventStatements` (event + delivery batch,
   `ON CONFLICT DO NOTHING` on the comment unique so a Meta redelivery is a
   no-op), `claimDelivery` (the statement above), `finishDelivery` (→ `SENT`
   with message id, only from `SENDING`), `failDelivery` (→
   `RETRYABLE_FAILED` / `PERMANENT_FAILED` / `DELIVERY_UNKNOWN` with error
   class + message, only from `SENDING`), `quarantineStaleSending`,
   `pendingDeliveries` (sweep: `QUEUED`/`RETRYABLE_FAILED` past their
   `next_attempt_at`, limited by a parameter, oldest first). Every transition
   is conditional on the current status; none of them read-then-write.
4. `src/db/test-d1.ts`: a helper that starts Miniflare with one D1 database,
   applies `migrations/*.sql` in order, and returns `{ db, dispose }`. Don't
   reuse `src/worker/harness.ts` (it bundles the Worker); copy its Miniflare
   import and options style.
5. Tests (`src/db/schema.worker.test.ts`, `src/db/deliveries.worker.test.ts`):
   port the archive tests' intent: duplicate comment is a no-op; once-per-user
   blocks a second counting delivery but not a non-counting one; one active
   automation per media; status `CHECK` rejects an unknown value; two
   concurrent `claimDelivery` calls (`Promise.all`) → exactly one winner;
   claim refused at the hour limit and allowed once the oldest claim ages
   out; finish/fail refuse a row not in `SENDING`; stale `SENDING` →
   `DELIVERY_UNKNOWN` and is then never returned by `pendingDeliveries` or
   claimable; a failing statement inside `recordEventStatements`' batch rolls
   back both rows (Miniflare only — note gate 8 in the handoff).
6. `src/db/README.md`: the state machine (one line per transition) and the
   "D1 rows written per comment" estimate for your schema (gate 2).
