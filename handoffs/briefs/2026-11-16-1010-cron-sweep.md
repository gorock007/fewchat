## Goal
The deployed Worker actually delivers: `queue()` hands batches to
`handleDeliveryBatch` with real dependencies built from `env`, and
`scheduled()` runs a bounded sweep every minute that quarantines stale
`SENDING` rows and processes a few overdue pending deliveries inline, so
nothing depends on the queue alone. Done = Miniflare tests drive the real
Worker's `queue()` and `scheduled()` end to end against a fake Meta origin, and
`pnpm lint && pnpm typecheck && pnpm test && pnpm build` pass.

       Health page's liveness signal).

       errors. No ids beyond counts, no content.
