## What changed
Five new pure modules, each with a colocated test file. Nothing imports `src/db`, `src/meta`, `next` or `process.env`; `now` and `random` are injected.
- `matching.ts` — `matchComment(text, rule)` → `{ matched, reason }`. NFKC + `toLocaleLowerCase("und")` on both sides, whitespace collapsed.
  - exact: junk (whitespace, punctuation, symbols, emoji, ZWJ/variation selectors) is allowed to flank the keyword, so keywords like `c++` still work.
  - whole_word: lookbehind/lookahead on `[\p{L}\p{N}\p{M}]`, applied only on a side where the keyword itself ends in a word character (so `#guide` and `c++` work). Keywords containing Han/Hiragana/Katakana/Thai/Lao/Khmer/Myanmar fall back to contains (those scripts have no word boundaries); documented in the code.
  - contains and any as specified. Reasons: `any_comment | exact | whole_word | contains | no_match | empty | invalid_rule`.
- `template.ts` — `renderTemplate`, `validateTemplate`, `DEFAULT_DM_TEMPLATE`, `MAX_DM_TEXT_LENGTH` (1000, with the TODO). One regex pass over the three known placeholders, so values are never re-expanded and `$&` in a value is inert. `validateTemplate(template, sample?)` returns `{ ok, errors[] }` with `unknown_placeholder`, `missing_resource_url`, `too_long`. Length is measured on the rendered text with a worst-case 30-char username unless `sample` overrides it.
- `resource-url.ts` — `validateResourceUrl`. http/https only; rejects credentials, whitespace/control chars, length > 2048 (also re-checked after normalisation), missing host. Returns the normalised URL plus a `not_https` warning for http.
- `eligibility.ts` — `PRIVATE_REPLY_WINDOW_MS`, `checkEligibility(createdAt, now, { safetyMarginMs })`. `expiresAt` is createdAt + 7 days − margin; `eligible` is `now < expiresAt`. Future-dated comments are eligible.
- `rate-limit.ts` — `decideSend(sentAtMs[], now, { perHour, burstPerMinute })` with rolling windows; `retryAt` is the later of the two limits' release times and frees as many slots as needed. `computeBackoff(attempt, opts)` uses full jitter over `min(maxMs, base·2^(attempt−1))`. A larger Retry-After wins and is not capped by `maxMs`. It returns `null` when the retry would land at or after `expiresAt`.
### Judgement calls (not in the brief)
- `matchMode` defaults to `whole_word` when omitted.
- `renderTemplate("Hey {username}! ", …)` gives `"Hey!"`, not `"Hey! "`: the brief's example keeps a trailing space but its rules also say to trim. I followed the rules.
- `renderTemplate` collapses only runs of spaces/tabs, so newlines in a template survive.
- `resource-url.ts` rejects `https:example.com` and `https:///example.com`, which `new URL` would otherwise accept, so what the owner typed is what is sent.
- A 2048-char resource URL can't fit in a 1000-char DM; `validateTemplate(template, { resourceUrl })` flags that, but the DM-length vs URL-length interplay belongs wherever the automation form is built.
